Drop partner / certification logos here (SVG preferred; PNG, WebP and JPG also work).
They appear automatically in the "Mitra & sertifikasi" strip under the homepage hero, sorted by
file name, with the file name as alt text (e.g. `01-halal-mui.svg` -> "halal mui").
Each logo sits on a cream chip in greyscale and returns to full colour on hover.
The strip is hidden while this folder has no logos.
